  The project

  irsimPy is the irsim C++ robotics simulator (e-puck robots) with a bridge
  added so that robot controllers can be written in Python. The simulator starts
  a Python controller from python/ and sends sensor data to it each step over
  stdin/stdout. The controller sends back wheel speeds and LED values.

  2026-06-23: first session

  - We built the Python bridge and simulator.py, which lists the available
    experiments. The irsimpy folder was renamed to python/.
  - We wrote Python controllers for experiments 1–11 (sensor tests). They now
    print sensor readings as well as moving the wheels.
  - We started experiment 30 (experiments/iri1exp with iri1_controller.py),
    including the red switch and LED options.

  2026-07-17: second session

  - Experiments 1–3 now print time instead of step number.
  - Experiments 1–11 take the robot's starting position and orientation from the
    Python file. The first version made the simulator hang because reading the
    Python file blocked on stdin. That was fixed with < /dev/null.
  - All floats now print with 4 decimals.
  - Each Python controller's file name now starts with its experiment number.
  - In experiment 10 (encoder), pos_x and pos_y were renamed to make clear they
    come from the simulator (RobotSim_pos_x and RobotSim_pos_y).

  2026-07-25: last session, on experiment 30 (IRI1)

  - The arena settings now live in python/iri1_controller.py: ARENA_CELLS_X/Y,
    ARENA_WIDTH/HEIGHT, and ARENA_MAP (% is a wall, # is free space).
  - In experiments/iri1exp.cpp, the new ReadArenaConfig() function reads those
    settings when the simulator starts. Editing the map doesn't need a
    recompile.
  - Lights and ground areas were removed from the Python file because they come
    from the param files.
  - Fixes in that session:
    - Walls appeared in the wrong place because the map was upside down. The
      rows are now reversed so the map in the Python file looks the same as the
      arena on screen.
    - Experiment 30 hung on startup. That was the same stdin problem, fixed with
      < /dev/null.
    - The map was ignored when a param file was given. ReadArenaConfig now runs
      whether or not there's a param file, for example with
      paramFiles/iri2Param.txt.
  - In iri1_controller.py, pos_x and pos_y were renamed to RobotSim_pos_x and
    RobotSim_pos_y.

  The session ended with everything working, and those changes are committed
  (6702403). The working tree has no uncommitted changes. What would you like to
  do next?
